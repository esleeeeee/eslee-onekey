# eslee OneKey

eslee OneKey는 단축키 하나로 게임 실행, 오디오 장치 전환, Discord 음성채널 입장, 게임 계정 전환까지 한 번에 처리하는 Windows 앱입니다. 게임을 끄면 오디오를 원래 장치로 되돌리되, 아직 통화 중이면 통화가 끝날 때까지 기다립니다.

문서 언어: **한국어** · [English](README.en.md)

## 최신 파일 다운로드

[GitHub Releases의 최신 릴리스](https://github.com/esleeeeee/eslee-onekey/releases/latest)에서 파일 이름이 `-Portable.zip`으로 끝나는 파일을 받으세요.

`Source code (zip)`과 `Source code (tar.gz)`는 개발용 소스 파일이며 실행 파일이 아닙니다. 일반 사용자는 `-Portable.zip`을 풀고 `Eslee.OneKey.App.exe`를 실행하면 됩니다.

.NET을 따로 설치하지 않아도 됩니다. 이 앱은 Windows 10 2004 이상 또는 Windows 11 x64 전용입니다.

## 이 프로그램으로 할 수 있는 일

- 단축키 하나로 게임과 통화 환경을 한 번에 준비하기
- 게임을 켤 때 헤드셋으로 바꾸고, 끄면 원래 장치로 되돌리기
- 통화 중일 때는 오디오를 되돌리지 않고 통화가 끝날 때까지 기다리기
- 지정한 Discord 음성채널에 자동으로 들어가기
- 단축키마다 다른 게임 계정으로 로그인해서 시작하기
- 게임이 실행 중인 동안에도 계정만 바꾸기

## 처음 사용하는 방법

기본 순서는 다음과 같습니다.

> 압축 풀기 → 실행 → 새 자동화 → 이름과 단축키 → 실행 파일과 감시 프로그램 → 오디오 장치 → Discord 연결과 채널 → 저장

1. 받은 zip을 원하는 폴더에 풀고 `Eslee.OneKey.App.exe`를 실행합니다.
2. `자동화` 화면에서 왼쪽의 `+ 새 자동화`를 누릅니다.
3. `기본 설정`에서 이름을 정하고 단축키를 지정합니다. 예를 들어 `Ctrl + Alt + Shift + V`처럼 다른 프로그램과 겹치지 않는 조합이 좋습니다.
4. `프로그램`을 켜고 실행할 파일을 고릅니다. `종료 감시 프로그램`에는 이 프로그램이 종료되면 자동화가 끝난 것으로 볼 프로세스 이름을 넣습니다.
5. `오디오`를 켜고 사용할 출력 장치를 고른 뒤, 자동화가 끝난 뒤 현재 장치를 유지할지 실행 전 장치로 되돌릴지 정합니다.
6. `Discord`를 켜고 `Discord 다시 연결`을 누릅니다. 연결되면 `음성채널 자동 입장`을 켜고 서버와 음성채널을 목록에서 고릅니다.
7. `이 자동화 저장`을 누릅니다.

설정 항목 옆의 `?` 표시에 마우스를 올리면 그 설정이 무엇을 하는지 설명이 나옵니다.

## 게임 계정 바꿔 쓰기

계정을 여러 개 쓴다면 자동화를 계정 수만큼 만들고 각각 다른 단축키를 줍니다. 예를 들어 `Ctrl + Alt + Shift + V`는 한국 계정, `Ctrl + Alt + Shift + A`는 아시아 계정으로 둘 수 있습니다.

계정 등록 순서는 다음과 같습니다.

1. 첫 번째 계정으로 게임 런처에 직접 로그인합니다. 이때 `로그인 상태 유지`를 켭니다.
2. 그 계정을 쓸 자동화에서 `계정 로그인`을 켜고 `현재 로그인 계정 등록`을 누릅니다.
3. `다른 계정 로그인 화면 열기`를 누릅니다. 런처가 닫혔다가 로그인 화면으로 다시 열립니다.
4. 두 번째 계정으로 로그인합니다.
5. 두 번째 자동화에서 `현재 로그인 계정 등록`을 누릅니다.

등록이 끝나면 단축키만 눌러 원하는 계정으로 시작할 수 있습니다.

- 게임이 이미 실행 중일 때 다른 계정 단축키를 누르면 오디오와 통화는 그대로 둔 채 계정만 바뀝니다.
- 같은 계정 단축키를 다시 누르면 아무 일도 하지 않습니다.
- 게임이 실행 중이면 계정을 바꾸지 않습니다. 게임을 먼저 종료하세요.

> **런처에서 직접 로그아웃하지 마세요.** 로그아웃은 서버에 저장된 로그인 정보까지 지웁니다. 이미 등록해 둔 다른 계정의 저장 세션도 함께 무효가 되어 전부 다시 등록해야 합니다. 계정을 바꿀 때는 `다른 계정 로그인 화면 열기`를 쓰세요.

## 자동화가 끝난 뒤 오디오

`오디오` 섹션에서 자동화 종료 후 동작을 고릅니다.

- **현재 장치 유지** — 게임을 꺼도 오디오를 그대로 둡니다.
- **실행 전 장치로 복원** — 자동화를 시작하기 전에 쓰던 장치로 되돌립니다.

복원을 골랐다면 `Discord 통화가 끝날 때까지 복원 기다리기`를 함께 켤 수 있습니다. 게임을 껐는데 아직 통화 중이면 헤드셋을 그대로 두었다가, 통화가 끝나면 자동으로 되돌립니다. Discord를 아예 종료한 경우에도 통화 중이 아니라고 보고 되돌립니다.

자동화가 실행 중이거나 복원을 기다리는 동안에는 화면 위쪽에 `지금 원래 장치로 복원`과 `현재 장치 유지 후 종료` 버튼이 나타납니다. 기다리지 않고 바로 결정하고 싶을 때 씁니다.

## Discord 서버와 음성채널 고르기

서버 목록에는 **내가 가입한 서버 중 OneKey 봇도 함께 있는 서버만** 나옵니다. 목록이 비어 있다면 봇을 그 서버에 초대한 뒤 `목록 새로고침`을 누르세요.

음성채널 목록에는 내가 볼 수 있는 채널만 나옵니다. 목록에 없는 채널을 써야 한다면 `목록에서 고를 수 없을 때`를 펼쳐 채널 링크나 ID를 직접 넣을 수 있습니다.

## 트레이

창을 닫아도 프로그램은 트레이에 남아 단축키가 계속 동작합니다. 트레이 아이콘을 우클릭하면 열기, 자동화 일시정지, 현재 상태 확인, 종료를 쓸 수 있습니다.

같은 PC에 [eslee Tray Folder](https://github.com/esleeeeee/eslee-tray-folder) 호스트가 실행 중이면 OneKey는 자체 트레이 아이콘을 숨기고 호스트의 트레이에 묶여 동작합니다. 호스트를 끄면 자기 아이콘을 다시 띄웁니다.

## 꼭 알아둘 점

- 단축키는 자동화마다 하나씩이며, 서로 같은 조합을 쓸 수 없습니다. 다른 프로그램이 이미 쓰고 있는 조합도 등록되지 않습니다.
- 꺼 둔 자동화는 단축키가 동작하지 않습니다.
- 계정 전환은 게임 런처가 이미 보관하고 있는 로그인 정보를 다루는 기능입니다. 아이디와 비밀번호를 입력하지 않으며, 게임 설치 파일이나 보호 드라이버는 건드리지 않습니다.
- Discord 연결이 거부되면 이 계정이 아직 OneKey 테스트 사용자로 등록되지 않은 것입니다. 앱 관리자에게 등록을 요청하세요.
- 음성채널 입장 권한이 없으면 목록에는 보여도 입장은 거부됩니다.

## 작동 원리

단축키를 누르면 자동화가 다음 순서로 진행됩니다.

1. 계정이 지정돼 있으면 현재 로그인된 계정을 확인하고, 다르면 저장해 둔 세션으로 바꿉니다.
2. 실행 파일을 시작합니다. 이미 실행 중이면 다시 켜지 않습니다.
3. 현재 기본 출력 장치를 기억한 뒤 지정한 장치로 바꿉니다.
4. Discord를 준비하고 지정한 음성채널에 들어갑니다.
5. 감시 프로그램이 종료될 때까지 지켜봅니다.

계정 전환은 런처가 사용자 폴더에 보관하는 로그인 세션 파일을 계정마다 따로 두었다가 바꿔 넣는 방식입니다. 런처는 로그인할 때마다 이 정보를 갱신하므로, 계정을 바꾸기 직전에 현재 계정의 최신본을 먼저 회수한 뒤 대상 계정 것을 넣습니다.

통화 여부는 이 PC의 Discord에 직접 물어봅니다. 외부 서버에 사용자 정보를 넘기지 않습니다. 서버 목록만 봇에게 확인하는데, 이때도 내가 이미 알고 있는 서버 ID를 보내고 그중 봇도 속한 것만 돌려받습니다. 봇은 자기 서버 목록을 알려 주지 않으므로 내가 모르던 서버가 드러나지 않습니다.

## 문제 해결

**단축키를 눌러도 아무 일도 일어나지 않습니다.**
자동화가 켜져 있는지 확인하세요. 목록의 체크박스가 꺼져 있으면 단축키가 등록되지 않습니다. 화면 위쪽에 단축키 등록 실패 안내가 있는지도 확인하세요. 다른 프로그램이 같은 조합을 쓰고 있으면 다른 조합으로 바꿔야 합니다.

**계정이 바뀌지 않고 로그인 화면이 뜹니다.**
저장해 둔 로그인 정보가 무효가 된 경우입니다. 계정 상태가 `재등록 필요`로 표시됩니다. 그 계정으로 다시 로그인한 뒤 `현재 로그인 계정 등록`을 누르세요. 런처에서 직접 로그아웃하면 이렇게 됩니다.

**Discord 연결 상태가 `Discord를 실행해 주세요`입니다.**
Discord가 실행 중인지 확인하세요. 실행 중인데도 그대로면 Discord를 다시 시작한 뒤 `Discord 다시 연결`을 누르세요.

**서버 목록이 비어 있습니다.**
OneKey 봇이 그 서버에 들어가 있어야 목록에 나옵니다. 봇을 초대한 뒤 `목록 새로고침`을 누르세요. 방금 봇을 초대했다면 잠시 뒤 다시 시도하세요.

**게임을 껐는데 오디오가 돌아오지 않습니다.**
Discord 통화 중이면 통화가 끝날 때까지 기다립니다. 바로 되돌리려면 화면 위쪽의 `지금 원래 장치로 복원`을 누르세요.

**자동화 도중 오디오 장치를 직접 바꿨습니다.**
사용자가 직접 고른 장치를 우선합니다. 자동 복원은 취소되고 현재 장치가 유지됩니다.

## 개인정보와 로컬 데이터

모든 데이터는 이 PC에만 저장됩니다. 저장 위치는 `%LOCALAPPDATA%\eslee OneKey`입니다.

- 게임 계정의 로그인 세션, Discord 토큰은 Windows DPAPI로 암호화해 별도 파일에 보관합니다. 현재 Windows 사용자만 풀 수 있으며 설정 파일이나 로그에는 남지 않습니다.
- 아이디와 비밀번호는 입력받지도, 저장하지도 않습니다.
- 통화 여부는 이 PC의 Discord에 직접 확인하므로 사용자 정보가 외부로 나가지 않습니다.
- 봇에 보내는 것은 내가 이미 알고 있는 서버 ID 목록뿐이며, 그중 봇도 속한 것만 돌려받습니다.

## 개발자용 문서와 빌드

```powershell
dotnet restore eslee-onekey.slnx --configfile NuGet.Config
dotnet build eslee-onekey.slnx -c Release --no-restore
dotnet test tests/Eslee.OneKey.Tests/Eslee.OneKey.Tests.csproj -c Release --no-build
dotnet publish src/Eslee.OneKey.App/Eslee.OneKey.App.csproj `
  -c Release -r win-x64 --self-contained true `
  -o artifacts/publish/win-x64 --configfile NuGet.Config
```

실행 파일은 `artifacts/publish/win-x64/Eslee.OneKey.App.exe`에 생성됩니다. `artifacts/`는 Git에서 제외됩니다.

저장소 구조:

```text
src/Eslee.OneKey.Core                    자동화 상태 머신과 플랫폼 독립 계약
src/Eslee.OneKey.Infrastructure.Windows  오디오, 프로세스, 단축키, DPAPI, Discord RPC
src/Eslee.OneKey.App                     WPF 화면과 트레이
tests/Eslee.OneKey.Tests                 자동 테스트
docs                                     요구사항, 아키텍처, 결정, API 계약, 시험 계획
```

자세한 내용은 [아키텍처](docs/ARCHITECTURE.md), [API 계약](docs/API_CONTRACT.md), [수동 시험 계획](docs/MANUAL_TEST_PLAN.md)을 참고하세요.

## 알려진 제약

- Windows 기본 오디오 장치 변경은 공개 API가 없어 `PolicyConfig` COM 인터페이스를 사용합니다. Windows 업데이트마다 실제 장비에서 확인이 필요합니다.
- Discord 음성채널 목록은 볼 수 있는 채널까지만 알려 줍니다. 입장 권한은 알 수 없으므로 권한이 없는 채널은 입장 시점에 거부됩니다.
- 자동 업데이트, 코드 서명, 설치 관리자는 아직 제공하지 않습니다.
