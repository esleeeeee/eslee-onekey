# OneKey v0.1.7

이번 버전부터 설치형을 제공합니다. `eslee-OneKey-v0.1.7-win-x64-Setup.exe`를 받아 실행하세요. .NET을 별도로 설치할 필요가 없습니다. 설치하지 않고 쓰고 싶다면 기존처럼 Portable ZIP을 풀어 `Eslee.OneKey.App.exe`를 실행하면 됩니다.

## 새 기능

- Windows 설치 관리자를 추가했습니다. `Program Files\eslee OneKey`에 설치되고 시작 메뉴에 등록되며, 설치 중에 바탕화면 바로가기와 로그인 시 자동 실행(트레이로 시작)을 고를 수 있습니다. `설정 > 앱 > 설치된 앱`에서 제거할 수 있습니다.
- 설치·업데이트·제거 전에 실행 중인 OneKey를 정상 종료합니다. 앱이 직접 종료하므로 바꿔 둔 오디오 장치 복원 같은 정리 작업을 마친 뒤 파일을 교체합니다.
- 새 버전 알림 문구가 설치 파일을 받도록 안내합니다. 새 설치 파일을 실행하면 덮어써서 업데이트됩니다.

## 포터블에서 옮기기

- 설정과 계정 정보는 `%LOCALAPPDATA%\eslee OneKey`에 있으므로 설치형으로 그대로 이어집니다.
- v0.1.6 이하 포터블은 종료 신호를 모릅니다. 설치 관리자가 "아직 실행 중"이라고 알리면 트레이 메뉴에서 OneKey를 종료한 뒤 설치를 다시 실행하세요.
- 자동 실행을 켜고 설치하면 포터블에서 등록한 자동 실행 항목이 설치 경로로 바뀝니다. 끄고 설치하면 옛 포터블 경로를 가리키던 자동 실행 항목을 지웁니다.
- 제거해도 `%LOCALAPPDATA%\eslee OneKey`의 설정은 지우지 않습니다.

## 알려진 제약

설치 파일에 코드 서명이 없어 처음 실행할 때 Windows SmartScreen 경고가 나올 수 있습니다. `추가 정보 > 실행`을 눌러 설치하세요.

## 검증

배포 시점의 자동 테스트 결과와 소스 커밋은 첨부된 `validation-manifest.json`과 TRX에 기록됩니다. 실제 게임 계정 전환, 오디오 장치 변경, Discord 채널 입장 시험은 이번 배포 검증에서 실행하지 않았습니다.
