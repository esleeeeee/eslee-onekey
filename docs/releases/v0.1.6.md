# OneKey v0.1.6

Windows x64 Portable ZIP을 풀고 `Eslee.OneKey.App.exe`를 실행하세요. .NET을 별도로 설치할 필요가 없습니다.

## 새 기능

- 트레이에서 실행 중인 OneKey를 다시 실행하면 기존 창이 열립니다. (#7)
- 자동화에 실행 인자를 지정해 런처에서 게임까지 시작할 수 있습니다.
- 계정별로 `게임이 켜져 있어도 종료하고 전환`을 선택할 수 있습니다. 기본값은 꺼짐입니다.
- 같은 계정의 자동화를 다시 누르면 실행 중인 게임을 앞으로 가져오거나 게임 실행을 다시 요청합니다. 연타에 의한 중복 실행 요청은 20초 동안 제한합니다.
- 앱 설정에서 바탕화면 자동화 버튼과 스피커·헤드셋 전환, 볼륨 믹서, 오디오 자동 전환 버튼을 켤 수 있습니다. 두 창은 끌어 옮기고 서로 붙일 수 있습니다.
- 자동화 실패를 트레이 알림으로 표시하며, 계정 고급 설정도 자동화 저장 시 함께 저장합니다. (#8)

## 수정 사항

- 강제 계정 전환으로 닫힌 게임의 종료 이벤트가 새 게임 시작 중 자동화를 끝내거나 오디오를 복원하는 문제를 수정했습니다. 새 게임이 실제로 시작된 뒤의 종료는 정상 처리합니다.
- 오디오 자동 전환을 끄거나 대상 장치가 연결되지 않아 전환을 건너뛴 실행은 Discord 통화 종료를 기다리지 않습니다.
- 붙어 있는 바탕화면 버튼과 오디오 창을 현재 모니터의 작업 영역 안으로 보정합니다.

## 동작 변경과 검증

지정한 오디오 장치가 연결되지 않았을 때는 오류를 표시하고 오디오 전환만 건너뛰며, 프로그램 실행은 계속합니다. 게임 강제 종료는 해당 계정 옵션을 켠 경우에만 사용합니다.

병합된 기능과 수정에 대해 자동 테스트 260개 통과, 실장비 조건부 테스트 4개 건너뜀, Release 빌드 경고·오류 0을 확인했습니다. 배포 시점의 최종 결과와 소스 커밋은 첨부된 `validation-manifest.json`과 TRX에 기록됩니다. 실제 게임 계정 전환, 오디오 장치 변경, Discord 채널 입장 시험은 이번 배포 검증에서 실행하지 않았습니다.
